# Supervisor feedback audit

**Source document.** `14199981_DATA72000_anno_7fc4.pdf`, an annotated copy of the compiled dissertation (35 pages), supplied by the student. Annotations were extracted programmatically with PyMuPDF (`page.annots()`), which reads the PDF's native highlight and sticky-note annotation objects rather than relying on manual transcription. Sixteen annotations were found, all authored by reviewer account `mbbsssg2`, spread across nine pages. No annotation was discarded.

**Method.** For each annotation the extraction records: the PDF page number (which matches the dissertation's own printed page numbers), the annotation type (`Highlight` or sticky-note `Text`), the reviewer's comment text, and — for highlights — the exact underlying manuscript text spanned by the highlight rectangle(s). This gives an unambiguous anchor for every comment; nothing below is inferred from memory or paraphrase of the annotated PDF.

**Column key.**
- **Location** — page number in the annotated PDF, and the corresponding dissertation chapter/section in the current `dissertation/overleaf/sections/*.tex` source.
- **Classification** — A prose/structure, B terminology/definition, C mathematical explanation, D results/discussion, E citation/evidence, F potentially requires new empirical evidence.
- **Experiment required?** — whether resolving the comment needs new empirical work (per the hard freeze in the task specification, this should normally be "No").
